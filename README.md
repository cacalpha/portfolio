## Projetos

### 1. CRM de prospecção com agente de IA
Agente de inteligência artificial que prospecta e conversa com clientes por WhatsApp para pequenos negócios. Lê informações públicas do negócio (Google Maps e Instagram) para personalizar o primeiro contato e conduz a conversa em etapas, da descoberta até a proposta. Possui um modo para o mercado dos EUA, em inglês.
- **Tecnologias:** Next.js, React, TypeScript, Prisma, Tailwind CSS, Zod, integração com WhatsApp e IA generativa.
- **Foi o meu primeiro projeto** de programação.
- **Código:** privado.

### 2. Mapa interativo com importação de dados
Site que mostra um mapa interativo e vai se preenchendo conforme dados novos são importados e tratados por um fluxo automatizado.
- **Tecnologias:** JavaScript, Supabase, rotas de API e deploy na Vercel.
- **Site:** [fill-the-map-usa.vercel.app](https://fill-the-map-usa.vercel.app)
- **Código:** privado.

### 3. Agente de day trade (somente análise e simulação)
Sistema com vários agentes de IA que analisa o mercado de criptomoedas, monta um plano de operação com risco definido e registra operações **simuladas** em um livro-caixa à prova de adulteração. **Nunca opera com dinheiro real.** O padrão do agente é "não operar" quando não há vantagem clara.
- **O que mostra:** regras explícitas para o agente, dados reais de mercado (Binance, CoinGecko, DexScreener, GoPlus), carteira simulada com taxas e derrapagem, e medição honesta dos resultados. Os resultados simulados atuais são de amostra pequena e negativos, e o projeto diz isso: é um laboratório para medir agentes, não uma promessa de lucro.
- **Tecnologias:** Python, agentes de IA, APIs públicas de mercado.
- **Código:** privado.

### 4. Aplicativo web com login, pontuação e ranking
Aplicativo com cadastro e login de usuários, sistema de pontos (XP) e página de ranking.
- **Tecnologias:** Next.js, React, TypeScript, Tailwind CSS e Supabase (autenticação e banco de dados com regras de acesso por linha).
- **Código:** privado.

### 5. Sites e páginas para negócios locais
Mais de 15 sites e páginas de apresentação para pequenos negócios (alimentação, floricultura, estética automotiva, festas, marcenaria, saúde), cada um com um conceito visual próprio, animações e foco em desempenho e uso no celular.
- **Tecnologias:** Next.js, React, Tailwind CSS, animações com Framer Motion, HTML e CSS.
- **Como trabalho:** começo pelo problema do cliente e pelo que ele vende, depois escolho o conceito, o visual e a tecnologia.
- **Sites de clientes:** mostro mediante autorização de cada cliente.
